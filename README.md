# PAYLOCA
APPLICATION DE LOCATION ET DIRETISSEMENT  

## Déploiement Render (frontend Vite)

Utilisez ces paramètres Render:

- **Root Directory**: `.`
- **Build Command**: `npm install --include=dev && npm run build`
- **Publish Directory**: `dist`
- **Rewrite SPA**: `/*` -> `/index.html` (**Rewrite**)
